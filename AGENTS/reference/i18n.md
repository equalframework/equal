# i18n reference

Use this reference for `i18n/{lang}/**/*.json` and user-facing labels, descriptions, help text, actions, routes, exports, sections, and error messages.

Key rules:

- Update every language already supported by the package.
- Preserve exact technical keys from model and view definitions.
- Include `label`, `description`, and `help` for impacted model fields.
- Translate view `name`, `description`, actions, routes, exports, and layout section labels.
- Add business error messages when validations, policies, actions, or providers expose user-visible error keys.
- Use `""` for intentionally empty values instead of omitting required keys.
- In PowerShell, read and validate translation files with explicit UTF-8 encoding.

Use `php run.php --do=core_test_translation-consistency --entity={EntityName} --lang={lang}` for model translation validation when available.
